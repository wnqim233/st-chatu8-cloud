Civitai

使用 Civitai v2 文生图工作流。填写支持平台在线生成的模型 AIR；LoRA 放在 additionalNetworks 中。负面词字段为 negativePrompt，尺寸自动对应原插件选择。省略 seed 则随机生成。

LoRA 参数格式示例
"additionalNetworks": {
  "urn:air:sdxl:lora:civitai:模型ID@版本ID": {"strength": 0.8}
}

把这一项加入上面的 JSON 对象，并替换成真实的 LoRA AIR；LoRA 与主模型的基础架构须兼容。

每次生成前先免费预估；超过上限或无法预估时不提交。预估和扣费有时间差，最终账单以 Civitai 为准。点击原插件生图按钮会在此范围内自动提交。
